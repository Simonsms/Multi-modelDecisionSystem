# UI 设计命名与出图顺序

## 1. 图片命名规则

建议统一使用：

```text
<page-name>-<status>-v<version>.png
```

示例：

- `decision-workspace-baseline-v1.png`
- `home-dashboard-concept-v1.png`
- `research-workspace-concept-v1.png`
- `result-summary-concept-v1.png`
- `analytics-dashboard-concept-v1.png`

命名原则：

- 全部用英文小写和短横线
- 文件名体现页面语义
- `baseline` 表示已确认基线
- `concept` 表示探索稿
- `v1/v2/v3` 表示版本

## 2. 建议出图顺序

先围绕已确认的工作台母版页扩展：

1. 首页
2. 调研页
3. 结果页
4. 分析页

原因：

- 首页决定入口体验
- 调研页承接当前最强需求
- 结果页承接主输出
- 分析页最后补，避免过早做后台样式

## 3. 首页生成 Prompt

```text
设计一个专业、克制、企业级的中文 Web 工作台首页，产品名称为“决策工作台”。

页面定位：
这是一个“渐进式 AI 决策支持系统”的首页，不是营销官网，不是聊天产品首页，而是一个内部工具的工作入口页。

页面目标：
- 快速进入最近会话
- 快速继续未完成工作
- 快速查看最近调研主题
- 快速查看最近生成的决策建议

布局要求：
- 保持与已确认的“决策工作台”母版页相同的视觉语言和导航风格
- 顶部导航保持一致：决策工作台 / 会话 / 调研 / 结果 / 分析
- 页面主体采用仪表盘式布局，但不要做成数据大屏
- 浅色主题，专业 SaaS 风格，中文界面

页面结构：

1. 顶部导航栏
- 产品名：决策工作台
- 导航：会话 / 调研 / 结果 / 分析
- 搜索框
- 新建会话按钮
- 通知 / 设置 / 用户头像

2. 页面主标题区
- 标题：工作台首页
- 副标题：继续推进未完成的决策会话，查看最近调研与建议

3. 主区第一行
- 左侧：最近会话
  - 3-5 个会话卡片
  - 每张卡片显示：标题、当前阶段、更新时间、状态
- 右侧：继续处理
  - 1-2 个高优先级会话
  - 强调“继续处理”按钮

4. 主区第二行
- 左侧：最近调研
  - 最近分析的开源项目 / 论文
  - 每项显示：名称、简短结论、标签
- 右侧：最近建议
  - 最近生成的决策建议卡片
  - 显示推荐方向摘要与来源会话

5. 底部区块
- 常见主题 / 热门问题类型的轻量展示
- 不要做复杂图表

风格要求：
- 和已确认的工作台母版页风格统一
- 中文界面
- 不要做营销视觉
- 不要大面积插画
- 不要未来感 AI 炫光
- 更像真实内部系统首页

输出要求：
- 高保真中文桌面端页面
- 1440px 宽
- 完整页面展示
```

## 4. 调研页生成 Prompt

```text
设计一个专业、克制、企业级的中文 Web 调研工作页，产品名称为“决策工作台”。

页面定位：
这是“渐进式 AI 决策支持系统”的调研页，用于管理开源项目、论文、案例等外部参考资料，并提炼可借鉴与不建议借鉴的结论。

页面目标：
- 展示调研对象列表
- 支持筛选与分类
- 展示每个调研对象的结构化结论
- 能看到它对当前候选方案和决策的启发

布局要求：
- 保持与已确认工作台母版页一致的设计语言
- 顶部导航一致：决策工作台 / 会话 / 调研 / 结果 / 分析
- 使用三栏布局或左中右信息结构
- 中文界面，浅色主题，专业 SaaS 风格

页面结构：

1. 顶部导航栏
- 产品名：决策工作台
- 导航：会话 / 调研 / 结果 / 分析
- 搜索框
- 新建会话按钮

2. 左侧栏
- 调研对象分类
- 来源筛选
- 标签筛选
- 例如：开源项目 / 论文 / 案例

3. 中间主区
- 调研对象卡片列表
- 每张卡片显示：
  - 名称
  - 来源类型
  - 简要定位
  - 核心结论
  - 标签：可借鉴 / 谨慎借鉴 / 不建议借鉴

4. 右侧详情区
- 当前选中对象详情
- 借鉴点
- 不建议借鉴点
- 对当前产品的启发
- 可落位阶段
- 关联候选方案

风格要求：
- 不要做成资料堆砌页面
- 更像“调研工作台”
- 信息层级清晰
- 强调结构化结论，而不是大段文字

输出要求：
- 高保真中文桌面端页面
- 1440px 宽
- 完整页面展示
```

## 5. 结果页生成 Prompt

```text
设计一个专业、克制、企业级的中文 Web 结果页，产品名称为“决策工作台”。

页面定位：
这是“渐进式 AI 决策支持系统”的决策结果页，用于展示最终推荐方案、备选方案、风险、待确认项和下一步建议。

页面目标：
- 结构化展示当前推荐方案
- 让产品经理、项目经理、开发都能快速理解当前结论
- 支持导出报告

布局要求：
- 与已确认工作台母版页保持统一风格
- 中文界面
- 浅色主题
- 更像结构化结论页，而不是编辑器

页面结构：

1. 顶部导航栏
- 决策工作台 / 会话 / 调研 / 结果 / 分析
- 搜索框
- 导出按钮

2. 页面主标题区
- 标题：决策建议
- 副标题：当前会话的推荐方向与依据

3. 主区左侧
- 推荐方案主卡
  - 方案名称
  - 一句话摘要
  - 推荐理由
- 备选方案区
  - 2-3 个备选项
  - 每项说明为什么未被选中
- 下一步建议区
  - 立即动作
  - 后续验证动作

4. 右侧栏
- 关键证据摘要
- 风险
- 待确认项
- 决策路径摘要

风格要求：
- 强调“结构化结论”
- 强调“可信赖和清晰”
- 不要做成海报
- 不要做成报告文档阅读器

输出要求：
- 高保真中文桌面端页面
- 1440px 宽
- 完整页面展示
```

## 6. 分析页生成 Prompt

```text
设计一个专业、克制、企业级的中文 Web 分析后台页，产品名称为“决策工作台”。

页面定位：
这是“渐进式 AI 决策支持系统”的分析页，用于查看会话数、阶段完成率、热门问题类型、模型调用量和基础成本视图。

页面目标：
- 提供最基础的产品运营观察面板
- 不做复杂 BI 平台
- 只体现第一版需要的关键数据

布局要求：
- 保持与已确认工作台母版页风格一致
- 中文界面
- 浅色主题
- 仪表盘风格，但不是大屏风格

页面结构：

1. 顶部导航栏
- 决策工作台 / 会话 / 调研 / 结果 / 分析

2. 页面主标题区
- 标题：分析
- 副标题：查看会话、阶段转化与模型使用概况

3. 第一行指标卡
- 会话总数
- 本周新增会话
- 当前进行中的会话
- 推荐方案采纳率

4. 第二行
- 阶段完成率 / 阶段转化漏斗
- 热门问题类型

5. 第三行
- 模型调用次数
- 粗粒度成本视图

风格要求：
- 保持专业、克制
- 不要过度图表化
- 不要做彩色数据大屏

输出要求：
- 高保真中文桌面端页面
- 1440px 宽
- 完整页面展示
```
